# Amqx's Aidoku Sources

This repository hosts sources from upstream as well as my own custom sources. See upstream's README for more info.

I will occasionally sync up with [upstream's](https://github.com/Aidoku-Community/sources) latest changes. The following extensions were added by me:

- [MangaPill](https://mangapill.com)
- [Violet Scans](https://violetscans.com)

## Stability

The extensions in this repo may not be as stable or as well-written as upstream's. Therefore, whenever upstream releases an extension for my already covered sites, I will replace with theirs. Furthermore, for the best experience, I would recommend sticking to upstream's extensions.
