# Amqx's Aidoku Sources

>[!IMPORTANT]
>This repo requires Aidoku version >= 0.8.4.

This repository hosts sources from upstream as well as a few of my own. See upstream's [README](https://github.com/Aidoku-Community/sources/blob/main/README.md) for more info.

I will occasionally sync up with upstream's latest changes. The following sources were added by me:

- [MangaPill](https://mangapill.com)
- [Violet Scans](https://violetscans.com)
- [MangaBall](https://mangaball.net)

## Stability

I would highly recommend users to stick with upstream's sources whenever possible. My sources may not be as 
well written or implemented. As a result of that, I will also prefer taking upstream's sources should they
add one for a site I already implemented.
